AI fluency drill — follow-up

Concept: tool-calling agents.

A useful business agent is not a chatbot with a better tone. It can read source data, choose tools, take bounded actions, respect forbidden actions, and report evidence. This is the move from AI answers to repeatable workflows.

Tonight’s drill: write one real workflow as trigger → data sources → allowed tools → forbidden actions → human approval point → evidence returned → success metric → exception path.
  • Best candidates: dealer/account prep, post-call follow-up, stale-opportunity cleanup, CRM hygiene, inventory/pricing exception review, manager daily visibility.
  • Quality bar: it should save 20–30 minutes, improve specificity, reduce missed follow-up, or expose a stale next action. If it does not change a rep action, manager decision, customer conversation, or operating metric, pick a narrower workflow.
  • Permission boundary: draft and recommend by default. Mutating CRM, sending external messages, spending money, changing records, or representing you externally requires explicit approval.
